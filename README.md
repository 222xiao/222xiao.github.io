# Dongfu Xiao · Academic Homepage

Static GitHub Pages site for [222xiao.github.io](https://222xiao.github.io). The layout follows the academic profile pattern of the [Academic Pages template](https://github.com/ycsek/ycsek.github.io): simple navigation, profile sidebar, and publication list. The implementation is original HTML, CSS, and JavaScript.

## Publishing

The public `222xiao.github.io` repository serves this site from the `main` branch root. Push updates to `main` and GitHub Pages will redeploy automatically at `https://222xiao.github.io/`.

## Edit

- `index.html`: profile, text, publication details, and links.
- `styles.css`: visual layout and responsive styles.
- `script.js`: English/Chinese language switch and mobile menu.

The profile photo is stored locally in `profile.jpg`. Publication entries are a curated selection; verify additions against the final publisher or preprint record before adding them.
